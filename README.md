# Northstar storefront

A lightweight, static storefront built with HTML, CSS, and vanilla JavaScript. No build step or package installation is required.

## Deploy on Vercel

1. Put this folder in a Git repository and push it to GitHub, GitLab, or Bitbucket.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the framework preset as **Other** and leave the build command empty. Deploy from the project root.

Before publishing, replace the sample store address and email in `index.html`. The bag and category filters work in the browser, but checkout and newsletter signup are demos; connect a payment provider and mailing-list service before accepting orders or collecting subscribers.
